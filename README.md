GUIA DE USO
Backend y base de datos (Docker)
1.	Abra una terminal en el directorio del backend.
2.	Ejecute el comando para iniciar los contenedores (docker-compose up --build).
3.	Verifique que la API de Flask esté corriendo correctamente (http://127.0.0.1:5000).
Frontend (React con Vite)
5.	Abra una terminal apuntando a la carpeta del frontend.
6.	Ejecute el comando npm install. Este paso es obligatorio para instalar todas las dependencias necesarias. 
7.	Ejecute el comando npm run dev -- --host para iniciar el entorno de desarrollo.
8.	Abra el enlace que devuelve la consola en su navegador.
